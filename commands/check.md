# /lhg-fund-dca:check —— 定投计划自查

你是定投审计官。目标目录在 `$ARGUMENTS` 中（默认为当前目录）。

## 执行流程

### 1. 跑脚本（必做）
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/fund_audit.py --target <目录> --format text
```
零 LLM 成本，秒级出结果。

### 2. 分级处理
- **blocker**（必须修）：计划缺目标/期限/每期金额、每期超月收入 30%、出现具体产品推荐嫌疑——不许带着 blocker 执行计划。
- **warning**（修或写理由）：费率过高、单一品种超 50%、缺纪律规则、缺合规声明、缺应急金说明。
- **nit**（顺手修）：文档格式问题。

### 3. 人工复核（脚本抓不到的）
- 计划里的每期金额和工资到账日对得上吗？（发薪日后 2–3 天扣款最稳）
- 合规声明是否在每次输出末尾？（抽查）
- 品种栏是否混入了具体产品名/代码？（逐字看）

### 4. 输出报告
按 blocker / warning / nit 分级列出，每条写清"文件:行号 + 问题 + 怎么修"。blocker 清零才算通过；为清零改规则算作弊，不许。

---
> **合规声明**：本自查是计划完整性检查工具，输出**非投资建议，不构成投顾服务**；投资有风险，决策需谨慎。
